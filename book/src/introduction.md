# Introduction

Walkers is a slippy map widget for [egui](https://github.com/emilk/egui). It runs natively and in
the browser.

Each chapter of this book is built around a demo, a small app showing one feature. It runs right
in the page, followed by its code. Every demo runs natively too, from
[Walkers' repository](https://github.com/podusowski/walkers):

```sh
cargo run -p demos -- raster
```
